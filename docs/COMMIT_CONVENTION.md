# 커밋 메시지 컨벤션

커밋 메시지는 아래 형식을 따릅니다.



```
<TYPE> 커밋 제목
```

- 헤더(`<TYPE>`)는 꺾쇠 괄호(`< >`)로 감싸고 대문자로 작성합니다.
- 헤더 뒤에 한 칸 띄고, 무엇을 했는지 짧고 명확하게 작성합니다.

## TYPE 종류
아래의 종류 외에는 사용하지 않는다.

| TYPE | 설명 |
|------|------|
| `<FIX>` | 긴급 버그 fix |
| `<FEAT>` | 새로운 기능 추가 |
| `<DOCS>` | 문서 추가/수정 |
| `<STYLE>` | 코드 포맷팅, 세미콜론 등 스타일 변경 (동작에 영향 없음) |
| `<REFACTOR>` | 기능 변경 없는 코드 리팩토링 |
| `<TEST>` | 테스트 코드 추가/수정 |
| `<CHORE>` | 빌드, 설정 등 기타 잡일 |

## 예시

```
<FIX> 긴급 버그 fix
<FEAT> 로그인 기능 추가
<DOCS> README에 설치 방법 추가
<CHORE> .gitignore에 .vs/ 추가
```
